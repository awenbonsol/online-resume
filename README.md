# Resume Website

A single-page static resume website with a PDF preview and download button.

## Use

1. Add your resume PDF to this folder as `resume.pdf`.
2. Edit `index.html` and replace `Your Name` with your name.
3. Deploy the folder to GitHub Pages or Vercel.

## Free Deployment

### GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository settings.
3. Go to **Pages**.
4. Set the source to the main branch and root folder.
5. Save.

### Vercel

1. Import the GitHub repository in Vercel.
2. Use the default static project settings.
3. Deploy.
